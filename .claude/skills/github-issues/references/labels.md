# Common Labels

Use these standard labels when applicable. If a matching label does not exist in the target repository, create it and inform the user.

| Label | Use For |
|-------|---------|
| `bug` | Something isn't working |
| `enhancement` | New feature or improvement |
| `documentation` | Documentation updates |
| `good first issue` | Good for newcomers |
| `help wanted` | Extra attention needed |
| `question` | Further information requested |
| `wontfix` | Will not be addressed |
| `duplicate` | Already exists |
| `high-priority` | Urgent issues |

## Label Synonyms

When a user uses informal terminology, map it to the closest standard label before checking the repository:

| User term | Candidate label |
|-----------|----------------|
| bug, broken, error, crash, not working | `bug` |
| feature, add, new, improvement, enhance | `enhancement` |
| docs, readme, wiki | `documentation` |
| urgent, critical, blocker | `high-priority` |
| duplicate, already reported | `duplicate` |

If no synonym maps to an existing label, create a new label in the repository and report its name and colour to the user.
