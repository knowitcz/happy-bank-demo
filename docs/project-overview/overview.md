# Happy Bank — Project Overview

Happy Bank is an educational banking application built with Python. It manages clients, accounts, and financial transactions (deposits, withdrawals, transfers).

## Technology Stack

| Concern | Technology |
|---|---|
| Web framework | FastAPI |
| Database | SQLite (development) |
| ORM / validation | SQLAlchemy · SQLModel · Pydantic |
| Test framework | Pytest |
| Migrations | Alembic |
| Python version | ≥ 3.10 |
| Package manager | `uv` (recommended) or `pip` |
